# MediaLab

Work in this project folder. Do not create worktrees or alternate copies. Use SSH
for any GitHub Git remotes.

This addon targets **WoW Forever**, interface **16001**. Blizzard's UI source is
available in a local wow-ui-source checkout (`WOW_UI_SOURCE`, or
`../../hub/wow-ui-source` from this folder); inspect `origin/forever` with
`git show` / `git grep` without switching or modifying that checkout. Retail's
`live` branch is a different API baseline. Start with
`Interface/AddOns/Blizzard_APIDocumentationGenerated/` for API shapes.

MediaLab covers icons, textures, atlases, sounds, control templates, fonts
and creature models. It is an **independent project**: other projects (such as
`../wow-addon-studio`) may use its scripts and `catalog/` output, but never add
code here that depends on or exists only for them. Plan in `sprint-hub/`. Keep it data driven: a media type
is a row in `ML.Kinds` (`kinds.lua`), a provider in `sources.lua` and a snippet
builder in `snippets.lua`. Prefer the client's own enumeration APIs; the
generated `data/` files are the fallback. Regenerate them with
`python3 scripts/build-catalog.py`. No Blizzard artwork or audio is bundled.
Keep indexing batched and create frames only when needed.
`MediaLab_Export/` is load on demand and only owns the `MediaLabExport` saved
variable; keep export data out of `MediaLabDB` so logins stay light.
`MediaLab_Icons/data.lua` is generated by `scripts/icon-metadata.py` (listfile
names, CASC pixel colors, LM Studio vision tags; caches in `.cache/icons/`).
Game data (DB2 tables, the CASC reader, the published database) lives in the
sibling `../codex-of-azeroth` project (`CODEX_DIR`); MediaLab only reads it,
through `scripts/codex_source.py`. `MediaLab_Models/data.lua` is generated by
`scripts/models-data.py` from the codex's `models` table. Never add game data
reading here; add a table to the codex and consume it.
Never write extracted artwork to the repo or the game folder.

## Checks

```sh
rg --files MediaLab MediaLab_Export tests scripts -g '*.lua' -0 | xargs -0 -n1 luac5.1 -p
lua5.1 tests/run.lua
python3 -m unittest discover -s tests -p 'test_*.py' -v
python3 scripts/package.py
```

Releases: `python3 scripts/release.py <version> [--interface N] [--fetch]`.

The Lua tests load the real TOC against a strict mock in `tests/wow.lua`; add
any new widget method there when the addon starts using it.

## Deploy after every change (the game does not read this repo)

```sh
scripts/deploy.sh            # copy MediaLab/ into the game's AddOns folder
scripts/deploy.sh --dry-run  # see what is out of date, copy nothing
```

The target is `WOW_ADDONS_DIR` or the first line of the ignored `.deploy-target`.
Never change other installed addons or saved variables. Tell the owner whether
`/reload` is enough (edits to existing files) or a client restart is needed
(new files or `.toc` changes).
